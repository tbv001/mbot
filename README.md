# Morbus Bots

Bots for the Morbus game mode in Garry's Mod. Currently work-in-progress.

## Installation

Navigate to your Garry's Mod addons folder, and then clone the repository:
```bash
git clone https://github.com/tbv001/mbot.git
```

## Commands

| Command | Description |
| :--- | :--- |
| `morbus_bot_add [name]` | Adds a bot, with custom name if provided. |
| `morbus_bot_kick [name]` | Kicks all bots, or kick only specific bot if name provided. |

## Convars

| ConVar | Default | Description |
| :--- | :--- | :--- |
| `morbus_bot_quota` | 0 | Sets the bot quota. |
